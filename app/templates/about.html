About This Project

A computer vision regression model that predicts banana ripeness from images.

🧠

Architecture

Fine-tuned ResNet-18 pretrained on ImageNet, adapted for regression. The model outputs a single continuous value: days remaining until overripe.

Input Image (224×224) → ResNet-18 Backbone → Regression Head → Days Remaining
📸

Custom Dataset

Bananas were photographed daily from purchase until overripe. Each banana's actual lifespan was observed — no fixed day assumptions.

  • Multiple bananas with varying lifespans
  • Banana-level train/val/test split (no data leakage)
  • Mild augmentation: flips, rotation, color jitter
🔬

Experiments

Three model architectures were compared to justify the final choice:

Model Approach
Baseline CNN Simple CNN from scratch
ResNet Frozen Feature extraction only
ResNet Fine-tuned Last 2 blocks unfrozen
📊

Evaluation

Regression metrics on completely unseen bananas:

  • MAE — Mean Absolute Error (average days off)
  • RMSE — Root Mean Squared Error
  • R² — Coefficient of determination

Evaluated on test bananas never seen during training.
